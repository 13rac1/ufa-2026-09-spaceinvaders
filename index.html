2 Who is playing?

Code

A rule-based program. An AI coding agent (Claude, directed by the operator) wrote its rules before the games; while it plays, no model runs.

< 0.1 ms per decision$0

Good at: anything that can be worked out exactly, every frame.

JEV

A decision model from TypeSafe. It is built on a large language model too, but it does not write an answer: it reads the probability of each option directly. That is why it is fast, and why its percentages mean something.

≈ 93 ms per decision≈ $0.00004

Good at: fast judgments between a few options.

LLMs

Large language models: Claude Haiku 4.5 and Qwen3.8 27B (open weights, through Ollama). They read the same question and write their answer as text, word by word, which is why they are slower.

≈ 1.1 s (Haiku), ≈ 2.4 s (Qwen)≈ $0.0014 (Haiku)

Good at: reading and reasoning in words.

Floors

Two players with no brain at all: one holds FIRE, one presses random buttons. Any real player should beat them.

< 0.1 ms$0

Good at: keeping everyone honest.

3 Anatomy of one decision

About 15 times a second, every player gets the current frame and picks one of six actions. Here is one real frame, and what happens to it.

  1. The decoder turns pixels into facts: where the ship, the aliens, the bullets and the shields are.
  2. The harness builds a request: those facts plus one question, "which of the six actions?". Every model gets the same request.
  3. JEV answers directly with a choice and probabilities. The LLMs get the same question through the organizers' System One adapter, which turns it into a prompt and reads the choice from their text.
  4. The game plays the chosen action for one step (4 frames).

      What if we tell the models how to win?
      
  
      We added the program's strategy to the question, in plain words, and asked each model to
    decide 300 real frames. Share of right answers, without and with the strategy:
      
  
      
  
      

  
      Let JEV choose the goal, and code do the rest
      
  
      TypeSafe's own guide says: keep known rules, calculations and execution in code; ask the
    model for the judgment. So we asked JEV one narrower question, "which target rule should
    the ship follow now?", and let code aim, fire and dodge.
