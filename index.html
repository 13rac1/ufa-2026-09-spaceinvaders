Holding FIRE beat the AI.

Just holding the FIRE button outscored JEV and two LLMs. A plain program, written by Claude before the games and running no model while it plays, beat all three by more than ten times.

JEV still beat both LLMs, 12x faster and 35x cheaper. During one Haiku decision, an alien bullet falls 64 pixels.

The short answer: the game is fully known, so everything can be calculated. The program calculates. The models have to guess where an alien will be when a shot arrives, and mostly can't.

One decision, 15 times a second

  1. The decoder turns the screen into numbers.
  2. Every model gets the same numbers and one question: which of six actions?
  3. The game plays the answer for one step.
